Commandes utiles du client sqlite3 (console PythonAnywhere)

Ouvrir / fermer la base

sqlite3 /home/iut90sqlite/database.db
  • .quit — quitter le client

Explorer la base

  • .tables — lister les tables
  • .schema article — voir la structure d’une table
  • .schema (sans nom de table) — structure de toutes les tables
  • .indexes — lister les index existants
  • .fullschema — schéma complet + statistiques
  • PRAGMA table_info(article); — détail des colonnes (nom, type, NOT NULL, valeur par défaut…)
  • PRAGMA foreign_key_list(article); — liste les clés étrangères d’une table

Affichage lisible

  • .mode column — affichage en colonnes
  • .headers on — afficher le nom des colonnes
  • .mode box — affichage en tableau avec bordures (souvent plus lisible que column)
  • .width 5 20 10 — fixer la largeur des colonnes en mode column

Requêtes

SELECT * FROM article;

Export / sauvegarde

  • .dump — affiche le SQL complet (structure + données), pratique pour un export texte
  • .backup fichier.db — copie la base entière dans un autre fichier
  • .output fichier.txt puis une requête, puis .output stdout — redirige le résultat d’une requête vers un fichier

Import / export CSV

  • .mode csv puis .import donnees.csv article — importe un CSV dans une table
  • .mode csv puis .headers on puis .output articles.csv puis SELECT * FROM article; — exporte une table en CSV

Autres commandes pratiques

  • .read script.sql — exécute un fichier de requêtes SQL
  • Flèche haut/bas — historique des commandes, comme dans un shell classique

Vérification d’intégrité

  • PRAGMA integrity_check; — vérifie que le fichier .db n’est pas corrompu

À privilégier au quotidien

Pour un usage régulier (cours + admin de la boutique) : - .dump pour un backup rapide avant modification - .mode box et .headers on pour un affichage clair
