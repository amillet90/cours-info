0. Téléchargez le code source du cours

Récupérez le code source ci-dessous :

Télécharger le code source

Puis, décompressez l'archive dans un dossier de votre choix.

1. Sélécteurs CSS avancés

Ouvrez le fichier A_advenced-selector.html dans votre navigateur et le fichier styles.css dans votre éditeur de texte.

Allez dans la section TUTO SELECTEURS et décommentez les différentes parties pour constater l'effet des sélecteurs sur la page.



2. L'attribut position

Ouvrez le fichier B_position.html dans votre navigateur.

Allez dans la section TUTO POSITION du fichier CSS et constatez de l'effet des différentes valeurs de l'attribut position.



3. Les Flexbox

Ouvrez le fichier C_flex.html dans votre navigateur.

Essayez de redimensionner la fenêtre de votre navigateur pour voir l'interêt des flexbox.

Allez dans la section TUTO FLEXBOX du fichier CSS et experimentez les effets des différentes propriétés des flexbox.

Le guide complet des flexbox est disponible ici : A complete guide to flexbox
